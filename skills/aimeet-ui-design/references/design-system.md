# デザインシステム

## 基準テーマ

今回作成したFABEX見本から抽出した再利用テーマ。AiMeet公式の全画面共通ブランド仕様と断定しない。ユーザー指定・イベントテーマ設定を優先する。

|項目|値|
|---|---|
|背景|`#faf9f6`|
|カード・ヘッダー|`#ffffff`|
|主色|`#a72c37`|
|本文|`#292724`|
|補助文字|`#76736c`|
|罫線|`#e7e3dc`|
|見本の本文|14px、Noto Sans JP → system sans-serif|
|カード角丸|5px|
|フォーム角丸|3〜6px|
|影|ホバー時だけ薄く、常時の強い影は避ける|
|ヘッダー高さ|PC 85px / スマホ 70px|
|コンテンツ|最大1440px、左右5.3%、スマホ左右20px|
|一覧左右カラム|218px / 残り、間隔35px|
|カード間隔|PC18px / スマホ11px|

本文や操作ラベルの判読性を優先する。見本の9〜11pxの補助文字はデザイン資料の具体値であって必須の最小値ではない。実装時は補助文字を原則12px以上とし、可読性・コントラストを検証する。日本語本文は行間1.7〜1.9。操作対象は可能な限り44px以上。キーボードフォーカスを明示する。

## 優先順位

構図・情報階層、寸法・余白、タイポグラフィ、色、装飾の順に合わせる。既存UIの親要素に狭いmax-widthや不要なpaddingがあれば原因を修正する。`!important`の積み重ねで隠さない。

余白は4/8/12/16/20/24/32/40/48pxを基本に、完成見本の具体値へ合わせる。罫線主体で整理し、カードやピルの入れ子を増やさない。実際の企業ロゴの色をフィルタで改変しない。

## レスポンシブ

- 1100px以下：カード2列、フィルター190px程度へ調整。
- 720px以下：左右20px、フィルターをドロワー/折り畳み、カードは内容に合わせ1列または2列。
- 390pxで2列の会社名や要約が読めなければ1列を選ぶ。
- ヘッダー・検索・ツールバー・パンくずが横にはみ出さない。
- PCのhoverだけで情報や操作を提供しない。

参照HTMLは素のHTML/CSSで実行可能。製品に移植する際にはフレームワークのLink、翻訳関数、テーマ変数と既存コンポーネントを使う。
