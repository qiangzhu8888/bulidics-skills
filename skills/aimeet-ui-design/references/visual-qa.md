# 画面比較と動作確認

## 比較手順

同梱の参照HTMLはHTTPで配信する。ブラウザ環境の許可されたプレビュー方式を使い、`file://`でのJSON fetch失敗を画面の不具合と混同しない。公開サイトや別イベントのデータを書き換えずに検証する。

1. 同じ画面幅・ズーム・スクロール位置で見本と対象を並べる/撮影する。
2. 最大幅、左右余白、左右カラム、検索位置、カード列数、カード高、ロゴ枠、見出し・要約・小間番号の順に差を確認する。
3. 差が残った項目を具体値で修正して再確認する。色の一致だけを合格にしない。
4. 1440px、768px、390pxで横はみ出しと操作性を確認する。未対応の画面幅や未取得スクリーンショットを確認済みと言わない。

## 最小限の機能確認

|対象|確認|
|---|---|
|検索|会社名、カナ、小間番号、空欄、0件|
|条件|カテゴリ＋エリア、全解除、総件数との整合|
|並び順|五十音、小間番号自然順|
|詳細遷移|カードの社名・中央・矢印、正しい企業・イベント|
|お気に入り|リンクに遷移せず切替、再表示、既存保存方式|
|詳細|登録済みの製品/資料等が失われていない、問い合わせ認証|
|欠損|ロゴなし、壊れた画像、長い社名、説明なし|
|データ|複数APIページ、重複、エラー、再試行|
|操作|Tab、Enter、フォーカス、フォームlabel、44px目安|
|表示|日本語と他言語、200%ズーム、固定ボタンの重なり|

既存の適切なテスト・ビルドを実行する。実装の細部をなぞるだけのテストを増やさない。ブラウザを利用できない場合は実施した静的確認と未検証の操作を分けて報告する。

## 報告例

「一覧を共通デザインへ変更。検索・複合条件・お気に入り・詳細遷移を確認。PCの表示を確認済み。390pxのブラウザ検証はこの環境では未実施。」
