# 出展者一覧

## 構成と寸法

同梱`assets/reference/index.html`を参照する。ヘッダー、控えめな紹介、検索、候補キーワード、左フィルター＋右一覧を基本とする。既存ページの情報が少ない場合に大きな販促ヒーローを新設しない。

- PCのカードは3列。中間画面2列、狭い画面1〜2列。
- 検索は枠線付き白背景、高さ約60px。入力欄を伸ばし、検索ボタンを右へ。
- 件数・ソート・カード/リスト切替を一覧上部の1行へまとめる。
- カードは画像領域112px、内側余白17px、ロゴは`object-fit: contain`、画像の縦横比を維持する。
- カテゴリ2件＋残数、会社名2〜3行、要約2行、小間番号のフッター。重要な会社名を省略しすぎない。タイトル全文を詳細で確認できる。
- ロゴなしは会社名の頭文字や控えめな背景で整える。企業名から除く法人格は見た目用に限り、正式社名を変えない。
- ロゴURLが壊れた場合も代替表示へ移る。
- カード全体のリンクとお気に入りを独立した兄弟要素にする。ボタンをリンクで囲まない。重ねる場合はz-index・focus-visible・クリック領域を確認する。
- リスト表示ではロゴ、社名・要約、小間番号を同じ行へ配置する。スマホでは折り返す。

## 状態と操作

- 会社名・カナ・出展内容・小間番号を検索し、NFKC、空白区切りなど既存仕様を確認する。
- カテゴリとエリアを組み合わせ、結果件数と条件チップ、全解除を提供する。
- エリアの意味はイベント設定に従う。小間番号先頭の数字を無条件に号館と呼ばない。
- 五十音順、小間番号の自然順、表示切替を提供する。カテゴリ数は複数所属で重複し得るため全社数と区別する。
- ページ分割や段階表示でも全体件数・検索対象を正確に扱う。未取得分を除外した検索結果を全件検索と表現しない。
- 詳細から戻ったときの検索・ソート・スクロール位置を既存設計に沿って保持する。
- ローディング、0件、再試行、画像失敗、長い社名を確認する。
